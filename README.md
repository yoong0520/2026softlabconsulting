# AI 코스웨어 실증 수업운영 컨설팅 (교수자 자가진단 · 컨설턴트 검토)

2026년 고등교육 에듀테크 소프트랩 실증 교수가 수업 운영을 자가진단하고, 컨설턴트가 이를 검토하여
수행공학 기반 수업컨설팅 모형(수업분석 → 원인분석 → 개선안 설계 → 협력적 평가)에 따라 피드백하는 단일 페이지 웹앱입니다.
실증 결과보고서 작성 도우미와는 별도 프로젝트이며, 드라이브 폴더와 수신기도 분리되어 있습니다.

## 흐름
1. 교수자: 기본 정보 → 자가진단 14문항(5점 척도 + 근거) → 활용 주차 → 어려움·요청 → AI 요약 → 「컨설팅 요청 제출」 → 접수 코드 6자리
2. 컨설턴트: 접수 코드로 불러오기 → 영역별 평정·의견 → AI 초안(수업분석·원인분석·개선안 목표·개입안·실행 계획·종합·후속) → 개입안 점수 → 「컨설팅 결과 제출」
3. 결과서(PDF·DOCX)는 사업단 드라이브에 저장되고, 교수자는 같은 코드로 결과를 확인

## 드라이브 분류
- 「2026 소프트랩 수업운영 컨설팅」 폴더 안에 컨설턴트별 폴더 → 배정 교과목별 하위 폴더로 자동 분류됨
- 명단에 없는 제출은 「0_배정 확인 필요(명단 외 제출)」 폴더로 들어감
- 컨설턴트·배정 교과목 명단은 개인정보 보호를 위해 저장소에 두지 않고 Apps Script(수신기) 안에만 보관함. 명단 변경 시 .gs의 ROSTER를 고치고 재배포

## 파일
- `index.html` — 앱 전체(HTML·CSS·JS 단일 파일). docx.js, html2pdf.js는 CDN에서 불러옴
- `relay/consult-receiver.gs` — 수신기 기본 골격(명단 미포함). 실제 운영 코드는 사업단이 별도 보관

## 수신기 설치(유은님 구글 계정, 약 5분)
1. https://script.google.com → 「새 프로젝트」(결과보고서 수신기와 별도 프로젝트로 만듦)
2. 기존 코드를 지우고 `relay/consult-receiver.gs` 내용을 붙여넣기 → 저장 → 프로젝트 이름 예: 소프트랩 컨설팅 수신기
3. 편집기 상단 함수 선택에서 setupFolders 를 고르고 ▶ 실행(처음 한 번, 컨설턴트별·교과목별 폴더 생성)
4. 「배포」→「새 배포」→ 유형 「웹 앱」→ 실행 주체 「나」, 액세스 「모든 사용자」→「배포」→ 권한 허용(이미 배포된 경우 「배포 관리 → 새 버전」)
5. 「웹 앱 URL」(…/exec)을 `index.html`의 `UPLOAD_URL` 값으로 넣고 main에 push

## AI
- 사업단 Cloudflare Workers AI 중계 서버(무료)가 기본 연결되어 있음. 개인 Anthropic API 키도 「AI 설정」에서 사용 가능
- 초안은 컨설턴트·교수자가 검토·수정하는 것을 전제로 함
